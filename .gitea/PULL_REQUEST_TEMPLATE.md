## Type of Change

- [ ] `feat` — новая функциональность
- [ ] `fix` — исправление дефекта
- [ ] `refactor` — без изменения поведения
- [ ] `perf` — производительность
- [ ] `test` — тесты
- [ ] `docs` — документация
- [ ] `build` / `ci` — сборка и CI
- [ ] `chore` — служебное

## Security & Quality Checklist

- [ ] Нет секретов, токенов и персональных данных
- [ ] Проверки (тесты, линтеры, CI, size guard) не ослаблены и не отключены
- [ ] Нет принудительных флагов и обходов штатных проверок
- [ ] Conventional Commits; тело коммита объясняет ПОЧЕМУ, а не что
- [ ] Для новой или изменённой функциональности есть релевантные тесты
- [ ] Изменения не затрагивают чужой плагин/окружение (иначе — отдельный issue)
